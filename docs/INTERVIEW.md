# 面接で説明するためのメモ

以下は学習用です。まだ理解できていない内容を、理解済みとして答える文章ではありません。

## 作品の狙い

題材は社内サポート。未対応の見落としと、過去の対処方法を探す手間を減らすため、状況管理と対応メモ検索を作った構成です。自分の経験ではどのような場面に使えるか、具体例を1つ考えてください。

## 説明する順番

1. どんな困りごとを解決する作品か。
2. 登録→対応中→完了→対応メモ検索を画面で実演する。
3. なぜ役割をクラスごとに分けたか。
4. 自分で変更した機能と、確認した結果。
5. 今の制約と、次に学ぶこと。
