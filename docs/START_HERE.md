# 最初の操作ガイド

## 1. 起動する

READMEの手順でJDKを確認し、ZIPを展開する。`run.bat --demo` または `bash run.sh --demo` で起動する。ブラウザで http://127.0.0.1:8080 を開く。

「javaは動くのにjavacが見つからない」場合は、JDKを入れ、開発ツールのbinフォルダへのPATH設定を確認する。PATHはコマンドを探す場所の設定。設定後はコマンド画面を開き直す。

## 2. 5分で一通り触る

1. サンプルの未対応・対応中・完了の件数を見る。
2. 「新規登録」を押す。
3. 件名「プリンターに印刷できない」、分類「PC・周辺機器」、内容「印刷待ちのまま止まる」を登録する。
4. 一覧から登録した件を開く。
5. 対応中に変更し、対応メモ「接続と印刷キューを確認中」と書いて保存する。
6. 完了に変更し、対応メモ「印刷キューを解除し、テスト印刷が成功した」と書いて保存する。
7. 検索欄に「テスト印刷」と入れて検索する。対応メモでも見つかることを確認する。
8. 状況を未対応に絞る。完了した件は表示されなくなる。
9. 検索を解除する。起動したコマンド画面でCtrl+Cで止める。
10. `--demo` なしで再起動する。自分の登録と完了メモが残っていることを確認する。

## 3. エラーを試す

- 件名をスペースだけにして登録する。エラーとなり、入力内容が残る。
- 対応メモを空にして完了にする。完了にならず、エラーが出る。
- 件名に `<b>テスト</b>` と書く。太字のHTMLにならず、文字として表示される。

## 4. コードを1か所変更する

`HtmlViews.java` の「問い合わせを、見失わない。」を自分の言葉に変更する。アプリを止めて再起動する。画面が変わることを確認し、`MY_CHANGES.md` に実際の変更を記録する。

## 覚えておくこと

- Javaコード・CSSを変更したら、アプリを止めて再起動する。
- CSSが変わらない場合はブラウザを再読み込みする。
- 起動の画面は、アプリ利用中は閉じない。
- データを初期化したい場合は、停止後に `data` を別の名前に変更して保管する。必要な記録を削除しない。
- iPhone単体ではこのJDK用アプリを起動できない。Windows・macOS・LinuxのPCで試す。
